# 2026-11-03

## 后台新增两个参数开关：H5 登录开关 / H5 注册开关

参数键（sys_config，config_type=Y 内置不可删）：
- `h5.login.enabled`：仅值为 `true`（忽略大小写/空格）时 H5 可登录，其余一律关闭，登录接口返回「系统关闭登录」
- `h5.register.enabled`：仅 `true` 时开放注册，关闭后隐藏注册入口且注册接口返回「系统未开启注册功能」

### 后端
- `PointsConstants`：新增 `CONFIG_H5_LOGIN_ENABLED` / `CONFIG_H5_REGISTER_ENABLED` / `H5_LOGIN_CLOSED_MSG` / `H5_REGISTER_CLOSED_MSG`
- `ISysConfigService` + `SysConfigServiceImpl`：新增 `selectH5LoginEnabled()` / `selectH5RegisterEnabled()`，
  私有 `selectSwitchEnabled(key)` 用 `Boolean.parseBoolean` 严格判定（未配置/空值=false，与"其他值即关闭"语义一致）
- `H5AuthController`：新增公开接口 `GET /h5-api/auth/config` 返回 `{loginEnabled, registerEnabled}`；
  `POST /login` 先判登录开关（在验证码校验之前，避免空耗验证码）；`POST /register` 先判登录开关再判注册开关

### H5 前端
- `src/stores/app.js`（新增 pinia store `useAppStore`）：`loadH5Config()` 进程内只请求一次，失败不缓存（下次导航重试）
- `src/api/auth.js`：`getH5Config()`，`loading:false, silent:true`
- `src/utils/request.js`：新增 `silent` 请求选项，静默请求失败不弹全局 toast
- `views/login/Index.vue`：`configReady` 门控，登录关闭时展示「系统关闭登录」占位卡，`registerEnabled` 为 false 时隐藏注册入口
- `views/login/Register.vue`：进入即校验，关闭则 toast + 回登录页；提交前二次校验
- `router/index.js`：全局守卫先 `await appStore.loadH5Config()`，`/register` 在开关关闭时直接重定向
